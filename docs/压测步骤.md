# 秒杀压测步骤（JMeter）

## 1. 准备数据
- 在项目根目录新建 `user_ids.csv`，每行一个用户 ID（无表头），例如：
  ```
  101
  102
  ...
  ```
- 确保库存已预热到 Redis（启动项目即可）。

## 2. 配置 JMeter
- 打开 `jmeter/秒杀压测.jmx`。
- 确认参数：线程数 200、Ramp-Up 0、循环 1；`HTTPSampler` 的 domain/port/path 已指向 `localhost:8081/api/seckill`。
- `CSV 数据文件` 指向上面的 `user_ids.csv`（变量名 `userId`）。

## 3. 运行与观察
- 点击运行，查看「聚合报告」：发送总数、成功数（code=200）、平均响应时间、错误率。
- 结合「查看结果树」区分三种业务失败：已抢光 / 请求频繁 / 手慢了。

## 4. 一致性校验（压测后执行）
```sql
USE seckill_db;
SELECT COUNT(*) FROM seckill_order WHERE product_id = 1;  -- 期望 ≤ 10
SELECT stock FROM product WHERE id = 1;           -- 期望 stock ≥ 0
SELECT id FROM product WHERE stock < 0;                    -- 期望 0 行
```
- `redis-cli`：`GET seckill:stock:1` 期望 ≥ 0，且与 DB `stock` 一致。
